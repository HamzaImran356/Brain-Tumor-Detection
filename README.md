# Brain Tumor Detection from MRI

A web application that uses deep learning to classify brain MRI scans into four categories: glioma, meningioma, pituitary tumor, or no tumor. Built with PyTorch, Flask, and React.

## Features

- 4-class classification: glioma, meningioma, pituitary, no tumor
- Drag-and-drop or click-to-upload MRI images
- Real-time predictions with confidence scores
- Probability distribution across all classes
- Responsive web interface

## Tech Stack

- **Backend:** Python, Flask, PyTorch, TorchVision
- **Frontend:** React, React Router, Bootstrap, Axios
- **Model:** Custom CNN (CNNModelV0)
